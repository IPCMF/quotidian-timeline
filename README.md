# Quotidian Timeline

An Obsidian plugin that draws a compact day timeline under the "Today:" heading of a daily checklist note, from timed tasks like:

```
- [ ] (11:15-1:00) #Ph Homework
- [ ] (15:15-16:45) #Ec Self study
```

- Blocks sized by duration, free gaps labelled, a now-line on today's note
- Click a block to edit time, day, title, colour, done; drag to move, resize or create (15-min snap)
- Day arrows (shift-click creates the adjacent day), relative-day badge
- Optional clean-up of untouched template-only day notes (to trash)
- Rendered on screen only: nothing is written into notes unless you edit through it

Personal plugin; install via [BRAT](https://github.com/TfTHacker/obsidian42-brat).
